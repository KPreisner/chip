CHIP: Confounding Hash Iteration for Passwords

CHIP hashes a salted password over and over until the low b bits of the digests have repeated C times. A salt whose chain runs past the upper bound is rejected and replaced. This page runs the real Python library in your browser; nothing you type leaves this page.

Source on GitHub Paper

Parameters

Each extra bit multiplies the work by about 1.4.

More collisions add work, each a little less than the last.

Salts whose chain runs longer are rejected.
